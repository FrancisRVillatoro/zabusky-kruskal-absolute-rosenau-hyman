# Analysis package of the article

This directory contains the scripts that compute the quantities of the article
that are not exported by the archived campaigns (momentum, catalogue of returns,
slice coefficients, structure of the zeros, initial layer, returns at other
lengths, variational equations and relative periodic orbits of the Galerkin
truncations) and that generate all the figures of the article, one PDF file per
panel.

Nothing here repeats a Picasso run. The postprocessing scripts read the immutable
ZIP files in `archives/` directly. The new computations are short and run on one
core. Results are written to `analysis/results/`, which is not distributed because
every file in it is regenerated by the commands below.

## Use

From the repository root, with Python 3, NumPy, SciPy, pandas and matplotlib
(the article used Python 3.13.18, NumPy 2.5.3, SciPy 1.18.1, pandas 3.0.5 and
matplotlib 3.11.2):

```sh
bash analysis/run_all.sh
```

The 40 panels of the twelve figures appear in `figures_reproduced/`. The numbers
quoted in the text and in the tables are printed by `paper_numbers.py` into
`analysis/results/paper_numbers.txt`.

## Scripts

| Script | Input | Output in `results/` | Article | Time |
|---|---|---|---|---|
| `momentum.py` | modal traces of series A and B, Galerkin traces, fields at the returns, AVF controls | `momentum_traces.csv`, `momentum_trace_returns.csv`, `momentum_field_returns.csv`, `momentum_curves.npz` | Section 5.1, Fig. 3 | seconds |
| `returns.py` | the same traces, 9C reports, base experiments | `return_catalog.csv`, `return_time_scaling.csv` | Tables 2, 3 and 4, Figs. 2 and 5 | seconds |
| `zero_structure.py` | fields at the returns (9A HDF5 export) | `zero_summary.csv`, `zero_crossings.csv`, `zero_local_profiles.csv` | Table 6, Fig. 9 | seconds |
| `initial_layer.py` | none | `initial_layer.csv`, `initial_layer.json`, `initial_layer_profiles.csv` | Section 6.2, Fig. 8 | 3 min |
| `lengths.py` | none | `length_returns.csv`, `length_curves.npz` | Table 3, Fig. 2 | 6 min |
| `gain_ladder.py` | none | `gain_ladder.csv`, `gain_ladder_traces.npz` | Table 9, Fig. 11 | 21 min |
| `rpo.py` | none | `rpo_orbits.json` | Table 5, Fig. 6 | 15 min |
| `rpo_linear_check.py` | `rpo_orbits.json` | `rpo_linear_check.csv` | Section 5.4, Fig. 6 | 30 min |
| `make_figures.py` | archives and `results/` | 40 panels, `mode7_ratio_sweep.csv` | all figures | seconds |
| `paper_numbers.py` | archives and `results/` | text listing | numbers in the text and tables | seconds |

`common.py` holds the readers of the archives and the modal definitions, and
`galerkin_ext.py` the Fourier-Galerkin models with their variational equations.
`test_galerkin.py` checks that `galerkin_ext.py` reproduces the archived events
of the truncations with cutoffs 21 and 35 of phase 9B (25 s).

## Notes on the computations

* `initial_layer.py` integrates the Pade semidiscrete system of the article with
  the implicit midpoint rule on geometric time steps. It is an independent small
  implementation and does not use the production solver.
* `rpo.py` solves for reflection-symmetric relative periodic orbits. The orbit of
  the cutoff 21 is found by Newton's method from the cosine, those of the cutoffs
  23 and 25 by continuation in the cutoff, and those of the cutoffs 27 and 29
  with the Levenberg-Marquardt option, each from the previous one. The
  iteration does not converge for the cutoffs 19 and 31:

  ```sh
  python3 analysis/rpo.py --cutoffs 19 --method lm --start analysis/results/rpo_orbits.json --start-cutoff 21 --out rpo_attempts.json
  python3 analysis/rpo.py --cutoffs 31 --method lm --start analysis/results/rpo_orbits.json --start-cutoff 29 --out rpo_attempts.json
  ```

  These end with norms of the closing conditions of 1.1e-4 and 3.6e-5 and write
  no orbit.
* The flux quadrature of the Galerkin models breaks the continuous translation
  invariance slightly. The closure defect reported for each orbit (1e-7 to 5e-6)
  measures this effect.
* The curves of the lattice sum in the third panel of Fig. 7 are evaluated by
  `make_figures.py` itself, which checks them against the values stored in the
  9A archive.
* All figures are produced by `make_figures.py` from numerical arrays. The file
  names are those used by the LaTeX source of the article.
